# Native research

Pipkin's Reference tools and credential reader are retired, without a replacement research abstraction. Use user-configured native documentation MCP, existing `gh` authentication, `npm search --json`, and local file/LSP capabilities.

[Configuration: native research setup](../configuration.md#native-research-setup) owns setup and cutover. [Web Fetch](web-fetch.md), [Browser](browser.md), and [LSP](workflow-tools.md) remain distinct capabilities. Existing credential files and historical results remain untouched.
